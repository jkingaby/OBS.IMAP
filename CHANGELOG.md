# Changelog

## 0.1.0 — Unreleased

- Initial self-hosted read-only IMAP service and eight MCP tools.
- Local stdio and OAuth-protected Streamable HTTP hosting.
- Multiple accounts, TLS, password and externally provisioned OAuth2 token authentication.
- Bounded UID search, MIME and attachment retrieval, principal-bound continuations and account authorization.
- Windows/Linux standalone publishing, non-root Docker packaging and automated test workflows.
- Opt-in local MCP tools for move, move to Trash, draft creation and authenticated SMTP submission with configurable user confirmation.

Provider OAuth refresh/onboarding, indexing and local message persistence remain outside scope. Client compatibility and verification evidence are documented separately.
